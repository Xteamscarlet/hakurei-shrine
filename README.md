# 博麗神社 · 微缩三维场景（Three.js）

用 Three.js 搭建的**博丽神社微缩立体场景**：一个可自由拖拽 / 旋转 / 缩放观看的收藏级小景观，三渲二（Toon Shading）画风，**无任何 UI 界面元素**。

## 运行

ES Module 需要通过 HTTP 提供（`file://` 会被浏览器 CORS 拦截），任选一种：

```bash
# Python
python -m http.server 8137

# Node
npx serve .
```

浏览器打开 `http://127.0.0.1:8137/`，拖动旋转、滚轮缩放。Three.js r0.160 通过 importmap 从 CDN 加载（首次打开需联网）。

## 场景构成

| 层次 | 内容 |
| --- | --- |
| 底座 | 正方形底座：三层错缝**石砌侧面**（轻微收分、圆角）+ 内收**木制夹层** + 外挑压顶石 |
| 地面 | 碎石庭院、砂土铺装、草地斑块、石板**参道**（成对石板 + 路缘石）、边缘小路、通往手水舍的踏石 |
| 神社主体（后方偏中央） | 石砌基坛、正面三级**石阶**、木地板广缘、朱红立柱、白壁、深色切妻大屋顶（宽檐 + 破风 + **千木** + **胜男木**）、缘侧栏杆 |
| 正面细节 | **注连绳**（绞纹环 + 纸垂）、**神社铃** + **木制拉绳** + 币束、**匾额**「博麗神社」、**赛钱箱**（投入口 + 铭牌） |
| 参道轴线 | **鸟居**（岛木 / 笠木起翘 / 贯 / 额束）、四座**石灯笼**、成对石柱 |
| 院落 | **手水舍**（石水钵 + 竹柄勺 + 通告）、**社务所 / 仓库**（拉门、障子窗、木桶）、**绘马架**、**御神签架**、**告示牌**、**扫帚**、木水桶、枯山水小景（白砂 + 三石） |
| 绿化 | 樱花树、松树、阔叶树、灌木丛、岩石、玉垣**围栏** |
| 氛围 | 空中飘落花瓣（随时间下沉回环）、地面散落花瓣与落叶、远景云团、天空渐变、雾 |

构图刻意做成**前低后高**：鸟居与石灯笼在前，开阔参道与庭院居中，神社本殿压在底座后方，形成微缩模型的前后层次。

## 文件结构

```
index.html          页面骨架（importmap + canvas，无 UI）
src/materials.js    色板、三渲二渐变贴图、卡通材质、反向法线描边、程序化噪点/文字贴图
src/base.js         正方形底座、地面、参道、草地、小路
src/shrine.js       本殿（基坛/石阶/立柱/墙体/屋顶/注连绳/铃与拉绳/匾额/赛钱箱）
src/props.js        鸟居、石灯笼、树木、灌木、岩石、玉垣围栏、枯山水
src/props2.js       手水舍、社务所、告示牌、绘马架、御神签架、扫帚、水桶
src/decor.js        散落花瓣/落叶、空中飘落花瓣、远景云团
src/main.js         渲染器、相机、灯光、控制器、装配与渲染循环
```

## 技术要点

- **三渲二**：`MeshToonMaterial` + 4 档 `DataTexture` 渐变贴图，把光照量化成赛璐璐分层；岩石与树冠用 `flatShading` 强化块面。
- **动画描边**：反向外壳法（`ShaderMaterial` + `BackSide` + 沿法线在视图空间外扩），为建筑 / 鸟居 / 灯笼 / 树木提供干净的线稿轮廓。
- **无贴图依赖**：材质以纯色 + 程序化 `CanvasTexture`（碎石噪点、匾额与告示牌文字）为主，风格干净统一。
- **第三视角**：`OrbitControls`（阻尼、禁用平移、限制俯仰与距离），保证始终能看全整个底座。
- 阴影使用单主光 + 半球补光 + 冷色轮廓光，`PCFSoftShadowMap`。

## 版本关系

同一场景的两个独立实现，分别在两个仓库：

- **本仓库（模块化版）**：`index.html` + `src/` 7 个模块，`OrbitControls` + 反向外壳描边
- **[hakurei-shrine-single-file](https://github.com/Xteamscarlet/hakurei-shrine-single-file)（单文件版）**：976 行 `index.html` 全部内联，自实现轨道控制（radius/phi/theta + 阻尼）与柔和暗角
